# LX 风格播放页

仿 [LX Music 移动版](https://github.com/lyswhut/lx-music-mobile) 的 Android 播放页排版，只借鉴布局，不含该项目的代码与素材。纯布局插件，不运行脚本，不申请权限。

- 全屏播放页：顶栏为收起按钮 + 歌名歌手 + 更多；封面与整页歌词左右分页；进度条下是「当前时间｜当前歌词｜总时长」；无底色的控制键均匀排开，单键切换播放模式；进度条与当前歌词用绿色强调（深浅色各一档）；封面带阴影，单击切到歌词页、双击收藏，切歌时缩放进入；去掉下方信息卡片。手机横屏为左右分栏。
- 宽屏播放页：左栏占 45%，封面、进度、控制键竖排。
- 全屏歌词页：顶部收起、歌名歌手与歌词设置，底部进度、时间与控制键；开启「自动隐藏控件」后上下两块随之淡出。
- 迷你播放器：顶部两角圆角，封面、歌名，第二行是当前歌词与时间，播放与下一首，底部细进度条。

需要 Melodia 插件 API 1.9。停用插件后恢复默认布局。
