# 流光风格播放页 1.0.0

需要 API 1.10 Android 宿主。

- `colors/palettes.json`：唯一的预设来源，8 个色系加中性预设。每个主题包含三层光斑、已唱歌词、已唱和声颜色。red 在 0° 和 345° 两个分段重复用于跨零点。
- `minSaturation: 0.16`：仅用 HSV 饱和度判断是否能可靠读出色相；低饱和度进入中性蓝灰。封面明度／饱和度不参与最终配色。
- `background/fluid.js`：使用宿主传入的命名颜色绘制与运动；浅色底为 #F7FAFD，深色底为 #1D1E20。三层同色系叠加，避免混杂发脏。
- `ui/player.json` / `ui/lyrics.json` / `ui/mini.json` 的预设表达式由 `package.py` 从预设来源生成，直接改生成字段会在下次打包被覆盖。未唱文字 45%、未唱和声 22%。打包时将歌词页的 `translationColor` 和 `romanizationColor` 设为 `unsungColor`，让当前行和其他行的翻译／音译使用相同的文字颜色。
- 歌词页 `layout: "host"` 使用宿主原有按钮布局；播放页保留插件排版和点击小歌词打开歌词页。
- `ui/mini.json` 使用同一预设的 glow3 作为渐变顶部来源、glow1 作为底部来源，保留 90° 线性渐变、原有混白／混暗比例及宿主控件。

构建：`python package.py`（生成配置并打包）；检查：`node test-background.cjs`。
导入 `fluid-player.melodiaplugin`，选择对应布局。停用插件即可恢复内置外观。
宿主只提供色相选择、画布颜色输入、歌词颜色与原有布局等通用接口，不内置预设色板。预设按封面目标取色选择，选定后的颜色在 800ms 内过渡，避免按封面过渡途中色相反复切换预设。

深色迷你条：两端统一选 glow1，顶部混黑72%、底部混黑58%，避免混灰和不同光斑色叠加造成浑浊。浅色迷你条保持原有顶部glow3、底部glow1及混白比例。

0.5.2：新增 android.fullPlayerWide → ui/player-wide.json。宽屏左栏使用插件排版，右侧歌词／信息卡片仍由宿主负责。在「设置 → 扩展 → 插件 → 播放器布局 → Android 宽屏播放页」中独立选择「内置布局」或「流光 · 全屏播放器」，或自动选择。默认自动策略沿用宿主已有规则；未声明宽屏的插件不会被列为该区域候选。宿主 API 1.10 补齐宽屏 canvas/canvasColors/header/cards 字段及 layout: host，修正横屏背景读取范围。
API 1.10 起，该区域同时控制普通横屏播放页和两栏宽屏左栏，背景同样独立。选择宽屏内置布局后不会回退到竖屏插件的光斑。
